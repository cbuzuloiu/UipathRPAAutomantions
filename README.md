# UiPath RPA Automations Portfolio

### Resilient Architecture | Business-Centric Design | Scalable Automation

Welcome to my central repository for **Robotic Process Automation (RPA)**. This collection showcases a transition from simple task automation to complex, resilient business process solutions using the **UiPath Ecosystem**.
## Repository Philosophy

My approach to RPA is built on three pillars:
1. **Resilience:** Building bots that don't break when the UI shifts or the environment changes.
2. **Scalability:** Leveraging frameworks like **REFramework** and **Dispatcher/Performer** models for high-volume processing.
3. **Business Value:** Every bot is designed to reduce FTE overhead, eliminate human error, and provide a clear ROI.
---
## Project Directory Structure

Each folder in this repository is a self-contained UiPath project, complete with its own specific documentation and process maps.

---
## Technical Stack

- **Development:** UiPath Studio (Modern & Classic Design Experience)
- **Orchestration:** UiPath Orchestrator (Queues, Assets, Storage Buckets, Triggers)
- **Frameworks:** Robotic Enterprise Framework (REFramework), Linear, and State Machine architectures.
- **UI Automation:** Fuzzy Selectors, Image Recognition, Anchor-Based Targeting.
- **Data & Integration:** Excel/Workbook Automation, SQL Integration, API/Web Services.
---
## How to Navigate

1. **Browse the Folders:** Select a project folder above to view the source code (`.xaml` files).
2. **Read the Docs:** Each folder contains a local `README.md` with a technical deep-dive and an execution schema.
3. **Review Dependencies:** Check the `project.json` in each folder for the required UiPath package versions.
